Rotator (optional)

Loading…

An antenna rotator on the network that speaks Hamlib's rotator protocol (rotctld, usually port 4533). The test only reads its position. Saving an address moves nothing: the rotator follows a satellite only after it is armed on the operating page, and it is never armed by a restart. Below the lowest elevation the rotator keeps following in azimuth and holds that elevation. With 0 to 180 travel, a pass that crosses north is worked flipped (azimuth plus 180, elevation over the top), so the azimuth rotator does not run through its end stop; with 0 to 90, such a pass means a long swing and the operating page says so beforehand.
